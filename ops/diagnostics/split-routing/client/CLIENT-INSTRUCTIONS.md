# Инструкция участнику диагностики

Цель — проверить, меняется ли сетевой маршрут для `.ru` и non-`.ru` hostname при включённом VPN. Скрипт только выполняет несколько HTTPS-запросов и создаёт небольшой текстовый TSV-файл. Он не изменяет настройки устройства.

## Какие данные попадут в результат

- название заданного сценария, например `vpn-off` или `vpn-on`;
- два тестовых hostname и их общий IP сервера;
- публичный IP, который увидел диагностический сервер;
- request id, время и технический статус HTTPS-запроса.

Скрипт не собирает cookies, пароли, файлы устройства, историю браузера, имя пользователя или содержимое VPN-конфигурации. Публичный IP всё равно является сетевым идентификатором: передавайте результат только владельцу теста согласованным способом.

## Перед началом

Владелец передаёт:

1. файл `collect-routing-diagnostic.sh`;
2. endpoint token;
3. точные названия двух сценариев и порядок переключения VPN.

На macOS открыть Terminal в папке с файлом. Требуются стандартные `curl` и `dig`.

## Сценарий 1 — VPN выключен

Полностью выключить VPN и убедиться, что устройство использует обычное подключение. Затем выполнить:

```bash
sh collect-routing-diagnostic.sh \
  --ru-host diag.systemcoach.ru \
  --non-ru-host diag.glide.club \
  --token '<TOKEN_FROM_OWNER>' \
  --scenario vpn-off
```

Скрипт создаст файл вида:

```text
routing-diagnostic-vpn-off-20260801T120000Z.tsv
```

## Сценарий 2 — VPN включен

Включить согласованный VPN-профиль, дождаться подключения и выполнить ту же команду с другим названием сценария:

```bash
sh collect-routing-diagnostic.sh \
  --ru-host diag.systemcoach.ru \
  --non-ru-host diag.glide.club \
  --token '<TOKEN_FROM_OWNER>' \
  --scenario vpn-on
```

## Завершение

Передать владельцу оба TSV-файла без редактирования. Если скрипт сообщает, что hostname имеют разные server IP, сертификат невалиден или запросы завершились ошибкой, не повторять команды многократно: сохранить сообщение и связаться с владельцем.

После подтверждения получения и завершения анализа удалить локальные TSV-файлы в согласованный срок.
